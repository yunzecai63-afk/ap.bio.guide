# Yunze Cai’s AP Bio Guide

A student-oriented AP Biology study resource with an original homepage, eight linked units, topic explanations, and review questions.

## GitHub Pages setup

All HTML files must be directly in the repository root (the same place as this README), **NOT** inside another folder. `index.html` is the entry point.

Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Public website: https://yunzecai63-afk.github.io/ap.bio.guide/

This is an independent study guide, not an official College Board resource.
