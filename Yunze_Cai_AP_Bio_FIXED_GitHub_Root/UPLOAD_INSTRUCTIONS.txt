IMPORTANT: Upload THE FILES INSIDE this folder, NOT the folder itself.

1. Open https://github.com/yunzecai63-afk/ap.bio.guide
2. On the main Code tab, click Add file -> Upload files.
3. Open AP_BIO_UPLOAD_THESE_FILES on your Mac, select ALL FILES INSIDE it (Command+A), and drag them into GitHub. Do not drag the folder.
4. Click Commit changes.
5. In Settings -> Pages, choose Deploy from a branch; Branch: main; Folder: / (root); Save.
6. In Actions, wait for the newest Pages build and deployment to get a green check.
7. Open https://yunzecai63-afk.github.io/ap.bio.guide/ and use Command+Shift+R if needed.

Before committing, the GitHub file list must show index.html immediately, not a folder named AP_BIO_UPLOAD_THESE_FILES.
