# Yunze Cai’s AP Bio Guide

A self-contained static website built for GitHub Pages. The homepage preserves the original landscape image, teal masthead, centered translucent hero, and three introduction cards. The eight unit pages include 60 lessons, topic-specific explanations, practice questions and answer keys, site navigation, responsive design, search within each unit, and locally saved review progress.

## Publish

1. Back up the existing repository files.
2. Upload all nine `.html` files to the ROOT of `yunzecai63-afk/ap.bio.guide` (replace files with the same names).
3. Ensure GitHub Settings → Pages → Deploy from a branch → main / root.
4. Visit `https://yunzecai63-afk.github.io/ap.bio.guide/` after deployment.

No build step, account, tracking, plugins, dependencies, or AI branding are present in the website. The homepage background image is externally hosted by Unsplash, as it is in the original homepage.

## Academic scope

Topic organization and published weighting reference College Board's *AP Biology Course and Exam Description* effective fall 2025. Explanations and practice questions are independently written. This study guide is not endorsed by College Board and is not a replacement for an AP course, textbook, or laboratory instruction.
