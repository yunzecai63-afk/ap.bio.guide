# Yunze Cai’s AP Bio Guide

A standalone, static AP Biology study website covering all eight official curriculum units. Each HTML file includes its own CSS and JavaScript: no framework, build system, database, downloaded images, or server is required. The homepage has a remote landscape background photo with a built-in CSS color fallback; losing network access to that image does not break navigation or lessons.

## Publish on an EMPTY GitHub repository

1. Download and **extract** `Yunze_Cai_AP_Biology_Standalone_UPLOAD.zip` on your computer. Do **not** upload the ZIP itself.
2. Open the extracted folder, select all the **files inside** it, not the folder.
3. Go to `https://github.com/yunzecai63-afk/ap.bio.guide`, click **Add file → Upload files**, drag all selected files, then **Commit changes**. GitHub must display `index.html` directly in the repository's main file list.
4. Go to **Settings → Pages**, set **Deploy from a branch**, branch `main`, folder `/(root)`, **Save**.
5. Go to **Actions** and wait for a green check on the newest Pages build.
6. Open `https://yunzecai63-afk.github.io/ap.bio.guide/`.

Don't delete/recreate the repository itself; an empty repository is fine. If you upload a folder instead of its contents, Pages may show a 404 because it cannot find root-level `index.html`.
