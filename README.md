# Yunze Cai’s AP Bio Guide

Nine standalone HTML pages and one local background illustration. No software installation, build system, external CSS, JavaScript, fonts, or image hosts are required.

## Upload to an empty GitHub repository

1. Extract the ZIP on your Mac. **Do not upload the ZIP file itself.**
2. Open the extracted folder. Select the **11 files inside** (not the folder). Upload using **Add file → Upload files** in `yunzecai63-afk/ap.bio.guide` on branch `main`.
3. Click **Commit changes**. Check the repository root lists `index.html` and `landscape.svg`, alongside the eight unit HTML files.
4. In **Settings → Pages**, set **Deploy from a branch** → `main` → `/(root)` → **Save**.
5. Wait for the newest green deployment at **Actions**, then open https://yunzecai63-afk.github.io/ap.bio.guide/ .

The website must not be uploaded in a subfolder. `index.html` belongs at the top level of `main`. Do not delete and recreate your entire GitHub repository. The site is an independent educational resource, not affiliated with College Board.
